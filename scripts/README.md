# scripts

## MIP Project

Created with mip package manager.

### Available Scripts

Add scripts to `mip.json`:

```json
{
  "scripts": {
    "start": "node index.js",
    "dev": "nodemon index.js"
  }
}
```

### Install Dependencies

```bash
mip install <package-name>
```

### Run Scripts

```bash
mip run start
```

### Global Installation

```bash
mip install -g <package-name>
```
